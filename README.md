## 作品

Composed by Hailey.S and Ting Ho Fung @Panlab Limited

© 2026 Panlab Limited. All Rights Reserved.

17 小節，F major（一個降號），4/4，♩ = 96。

和弦進行：F / C / Dm / Am / B♭ / F/A / B♭ / C，重複兩次，第 17 小節以 F 結束。
