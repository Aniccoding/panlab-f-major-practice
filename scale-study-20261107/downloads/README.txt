2026-11-07 新練習曲：音階、穩定拍子與節奏感。
F major（一個降號），4/4，四分音符 = 96。
第 1–8 小節（A）：兩個旋律聲部全部使用四分音符。
第 9–17 小節（B）：兩個旋律聲部全部使用八分音符。
每句是逐級上山或落山的音階短句，句內保持同一種音符時值，句間留白。
和弦：F | C | Dm | Am | Bb | F/A | Bb | C，重複兩次；第 17 小節 F 收結。

每個音標示 C、D、E、F、G、A、B♭，沒有八度數字。
雙音和弦的兩個音名分成上下兩行，上行對應較高音，下行對應較低音。

Scores/PDF：總譜及七份學生分譜。
Scores/MuseScore：對應八份可編輯的 MuseScore Studio 原生 MSCZ。
Audio/Harp：總譜及七個聲部的 Harp demo，共八個 MP3。
Audio/Harp-with-Click：相同八個 demo 加 click。

所有 demo 使用 MuseScore Basic 原生 Harp；已停用和弦符號自動發聲。
Click 每四分拍發聲，每小節第一拍加重；沒有額外預備小節。
音訊保留完整 17 小節及聲部休止，約 45.5 秒，包括收結餘韻。

請先解壓 ZIP，列印 PDF，或在 MuseScore Studio 使用 File > Open 開啟 MSCZ。
